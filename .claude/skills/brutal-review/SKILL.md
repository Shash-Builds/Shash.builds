---
name: brutal-review
description: Get a blunt, structured critique of a plan, pitch, resume or code from a different AI model (OpenAI, xAI, Anthropic, Google, local Ollama or the claude CLI). Returns a verdict, a score out of 100, ranked weaknesses with fixes, and the likeliest reason it fails. Use for "brutal review", "second opinion", "tear this apart".
---

This lets the tool work in sessions opened inside this repository. The real
skill ships as a plugin. Read `skills/brutal-review/skills/brutal-review/SKILL.md` and follow it.
Wherever that file refers to `SKILL_DIR` or to the skill's own folder, use
`skills/brutal-review/skills/brutal-review` (relative to the repository root).
