# Power: Numbers

For pricing, unit economics, budgets, forecasts, conversions, salaries, payouts.

## Method
1. Write every calculation in code (Python) and show the inputs, so the user can change one and rerun.
2. Say where each input comes from (the user, a fee page with its date, a report) and mark assumptions.
3. Give the answer first, then a small table, then what would change it most.
4. Money in the user's currency with the right separators (for India: Rs 1,20,000 or Rs 1.2 lakh).
5. Salaries: split fixed and variable, monthly and yearly; subtract costs the user will pay (commute, rent)
   when comparing offers.

## Never
Round away a loss, present a guess as a fact, or give tax or legal advice as final; point to a professional.

## Done when
Every number reproduces from the code, inputs are sourced, the user got the answer in one line.
