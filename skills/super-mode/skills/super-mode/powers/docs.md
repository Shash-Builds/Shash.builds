# Power: Docs

For Google Docs, Sheets and Slides, reports, link lists, submission packs.

## Method
1. Follow the brief's exact structure: list what was asked, in that order, then extras after.
2. Put every link into the document before creating it (connected tools may not allow edits later).
3. Short sentences, topic first, a links box at the top, sources in a separate doc when there are many.
4. After creating: check sharing (anyone with the link can view, if the user wants that) and open every
   link logged out. Apps and pages must be share links, not the owner's editor links.
5. Give the user the link and one line on what is inside.

## Done when
The structure matches the brief, every link opens for someone who is not the owner, sharing is set.
