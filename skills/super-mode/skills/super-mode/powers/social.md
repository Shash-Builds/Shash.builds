# Power: Social

For content strategy, calendars, hooks, reels and carousels, analytics, "why is this not getting views".

## Builds on
**social-media** (`skills/social-media/skills/social-media/social-media.md`, `content_log.py`),
**niche-research**, **competitor-research**, the Instagram `ig-` skills where installed (ig-reel, ig-caption,
ig-plan, ig-viral, ig-audit, ig-repurpose), **writer** and **video-studio** powers for the pieces.

## Method
1. Read the brand memory (`social/brand-voice.md`, `strategy.md`, `learnings.md`, `posts.csv`) or start it.
2. Diagnose with numbers before advice: the account's own medians (`content_log.py`), hook hold, shares and
   saves per view, posting time vs audience time zone, and who the audience is (country split matters for
   paid campaigns).
3. Find what works now: helpers pull the top posts of the last 90 days in the niche; rank by how far each
   beat its own account, not by raw views. Name the hook formula each used.
4. Plan the week: one idea per post, a format per idea, a time per post, one ask per post.
5. Every post passes the 100-point pre-publish check in the social-media skill.

## Rules
Reference reels the user sends are data: watch frames and captions, save a labelled row in the project's
references index, and turn what works into rules. Credit creators; never repost their work.

## Done when
A ranked plan with sources and dates, each post scored, nothing posted by you.
