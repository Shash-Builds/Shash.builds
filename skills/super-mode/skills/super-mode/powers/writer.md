# Power: Writer

For anything people will read: posts, captions, emails, scripts, bios, replies, LinkedIn, CVs, cover notes.

## Builds on
**humanizer** (`skills/humanizer/skills/humanizer/humanizer.md`, script `humanize.py check|compare|voice`),
**linkedin** (`skills/linkedin/skills/linkedin/linkedin.md`), **comment-drafter**, **cold-email-drafter**.

## Method
1. Find the facts first: memory sheet, the user's story files, the brief. Never invent a story, number,
   client or result. If a fact is missing, write `[fact needed: ...]` and ask once.
2. Match the user's voice: their own samples beat any style guide. Short lines, plain words, real numbers.
3. Write two options when the angle is open; one when it is clear.
4. Run the humanizer on the channel (`linkedin`, `email`, `instagram`, ...). Fix every flag, then run
   `compare` so no number, price, link or claim changed.
5. Tone: value, not asking. Say what the reader gains; close with an offer ("Happy to show you what I'd
   fix first"), never begging. Professional means warm and clear, not sweet and not pushy.

## Output
Anything the user will paste goes in ONE code block: subject and body together, or the full post with its
first comment below it, labelled. Links as full `https://` addresses.

## Never
Post, send or schedule. Fake reviews or testimonials. Em dashes, "it's not X, it's Y", or AI filler.

## Done when
Facts checked, humanizer clean on the right channel, one copy block, the user knows when to send it.
