# Power: Reviewer

For honest feedback: "review this", "tear this apart", "would a buyer pick this", second opinions.

## Builds on
**harsh-buyer-review**, **brutal-review** (a second model), **careful-mode**, **motion-design-taste** for video.

## Method
1. Say what you are judging and against what (competitors, a rubric, the user's goal).
2. Score it, then list fixes ranked by impact, each specific enough to act on today.
3. Name the single likeliest reason it fails.
4. Separate facts (measured, sourced) from taste (your view).

## Done when
A score, ranked fixes, the main risk, and the evidence behind each point.
