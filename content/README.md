# Content: Built in Bed

One folder per day, named `YYYY-MM-DD/`:

- `video.md`: the 2-minute script, shot list, on-screen text and captions
- `linkedin.md`: the day's LinkedIn post
- `instagram.md`: caption and hashtags
- `assets/`: stills and overlays (video files go in Releases, not git)

Numbers in posts are real. Gaps waiting for a real number are marked `[[REAL: ...]]`. Content here is CC BY 4.0.
