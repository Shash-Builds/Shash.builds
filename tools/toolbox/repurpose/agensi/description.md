Every video you make can be four more posts. This skill writes them from the transcript and then checks them, so you don't post a caption with four hashtags or a chapter list YouTube ignores.

From one transcript you get:
- A LinkedIn post with a first line short enough to show before "see more"
- An Instagram caption with exactly 3 hashtags on the last line
- An X thread, every post under 280 characters
- A YouTube title, description and chapters taken from the real timestamps

The writing rules are strict: plain words, only facts from the transcript, no em dashes, no hype words like "game-changer" or "unlock".

How it works:
- In Claude, the skill builds the prompt, Claude writes the four pieces, and a script checks every limit (sections, lengths, hashtags, chapter spacing, dashes, stock phrases) until they pass.
- On the command line with no AI at all, it writes a ready prompt file you can paste into any chat model, then checks the answer.
- With Ollama installed, it can draft the posts with a free local model.

No API key, no packages, nothing posted for you.
