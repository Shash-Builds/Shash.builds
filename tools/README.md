# Tools

Open-source web tools for local service businesses and the designers who build for them. Plain HTML, CSS and JavaScript, so they deploy anywhere static.

| Tool | What it does |
| --- | --- |
| [One-Page Starter](one-page-starter) | A one-page site for a local service business, from one CSV row |
| [Lead Tracker](lead-tracker) | Every website lead in a Google Sheet, with where it came from |
| [Level-Up Dashboard](level-up-dashboard) | A Google Sheet template to track a build-in-public run |

They work together: build the site with One-Page Starter, pass `--sheet-url`, and every quote request lands in the Lead Tracker sheet.
